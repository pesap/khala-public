# Obsidian

A knowledge base that works on local Markdown files.

## Key Features

- Local-first: files stored on your machine
- Markdown: plain text, portable format
- Graph view: visualize note connections
- Plugins: extensible architecture
- Backlinks: see what links to this note

## Philosophy

- Your data is yours (not locked in cloud)
- Markdown is forever (no proprietary format)
- Links are first-class (networked thought)

## Limitations

- Requires the app for full functionality
- Proprietary sync service
- Graph view is vendor-specific

## Pure Markdown Alternative

You can achieve similar results with:

- Standard markdown files
- Wiki-links syntax `[[Note Name]]`
- Generated semantic atlas
- Version control for history
