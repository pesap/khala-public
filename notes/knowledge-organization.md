# Knowledge Organization

Systems and approaches for organizing information for retrieval and use.

## Traditional Approaches

- Hierarchical folders: tree structure
- Tags: flat labels
- Links: network/graph structure
- Search: full-text indexing

## Semantic Approaches

- Embeddings: organize by meaning similarity
- Clusters: automatic grouping
- Faceted navigation: multiple dimensions

## Pure Markdown Benefits

- Portable (any text editor works)
- Version control friendly
- Future-proof (no proprietary format)
- Simple to read and write

See [[Semantic Navigation]] ([Semantic Navigation](semantic-navigation.md)) for
a modern take on this.
