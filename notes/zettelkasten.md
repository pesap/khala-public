# Zettelkasten

A note-taking and knowledge management system developed by Niklas Luhmann.

## Principles

1. Atomic notes: one idea per note
2. Unique IDs: each note has a permanent identifier
3. Linking: notes reference each other
4. Indexing: entry points to topics
5. Clustering: notes naturally form clusters

## Contrast with Folders

Unlike hierarchical folders, Zettelkasten uses sequential numbering (notes are
numbered as added), branching (new notes branch off existing ones: 1a, 1b,
etc.), and rich cross-references that create emergent structure.

This creates a "web of thought" rather than a rigid hierarchy.

## Modern Implementations

- [[Obsidian]] ([Obsidian](obsidian.md)) - graph-based markdown notes
- [[Roam Research]] ([Roam Research](roam-research.md)) - block-level references
