# Roam Research

A note-taking tool for networked thought.

## Key Features

- Block-level references: link to specific paragraphs
- Bidirectional links: automatic backlinks
- Outliner: hierarchical bullet structure
- Daily notes: entry point for capturing
- Graph database: query your knowledge

## Unique Aspects

Unlike other tools, Roam treats blocks as first-class citizens (you can
reference specific content), every item as a page (even tags become pages), and
daily notes as the primary index.

## Limitations

- Proprietary format (not plain markdown)
- Expensive subscription
- Locked into their ecosystem
- Performance issues with large graphs

## Comparison to Pure Markdown

Pure markdown can achieve:

- Wiki links: `[[Page Name]]`
- Headings as anchors: `# Section` links
- Daily notes: simple dated files
- Backlinks: generated at build time

But loses:

- Block-level references
- Real-time graph queries
- Live collaboration

See [[Knowledge Organization]]
([Knowledge Organization](knowledge-organization.md)) for trade-offs.
